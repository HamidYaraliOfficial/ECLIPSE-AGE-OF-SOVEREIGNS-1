# ECLIPSE: AGE OF SOVEREIGNS (اکلیپس: عصر فرمانروایان)
[English](README.md) | **فارسی** | [中文](README.zh.md)

یک بازی استراتژی سه‌بعدی در مرورگر (Three.js، بدون نیاز به build). سازنده: **حمید یارعلی** — https://github.com/HamidYaraliOfficial

## وضعیت: نسخه‌ی Vertical Slice (نسخه ۰٫۱)
پیاده‌سازی و تست‌شده: کره‌ی زمین سه‌بعدی (چرخش، زوم، انتخاب شهر)، ۱ کشور بازیکن + ۳ کشور هوش مصنوعی، ۵ شهر، اقتصاد (پول، غذا، آهن، انرژی، جمعیت، رضایت، مالیات)، درخت فناوری شاخه‌ای با ۸ فناوری، سربازگیری، نبرد خودکار (فناوری، روحیه، تدارکات، زمین)، دیپلماسی (قرارداد تجاری، جنگ، صلح — هوش مصنوعی رفتار شما را به یاد می‌آورد)، هوش مصنوعی فعال، شرایط پیروزی، ذخیره/بارگذاری (۳ اسلات + ذخیره‌ی خودکار، نسخه‌دار و دارای checksum).

**هنوز پیاده‌سازی نشده (و در بازی نمایش داده نمی‌شود):** نبرد تاکتیکی سه‌بعدی بلادرنگ، آب‌وهوا، جاسوسی، سیاست داخلی، ۲۰۰+ فناوری، ۴۰+ کشور، صدا، چندنفره، پنل دیباگ.

گرافیک: Bloom، تون‌مپینگ سینمایی، زمین رویه‌ای با bump، چراغ شهرها در سمت شب، ابرهای متحرک، جو سیاره، چرخه‌ی شب و روز، حلقه‌های قلمرو، مسیرهای متحرک تجارت (طلایی) و جنگ (قرمز)، ورود سینمایی. همچنین: موتور رویداد پویا (بر پایه‌ی وضعیت بازی) و صدای تطبیقی.

## اجرا
```
npm start    # یا: python3 -m http.server 8080
```
آدرس http://localhost:8080 را باز کنید (بار اول به اینترنت برای Three.js نیاز است). کلید Space = پایان نوبت.
