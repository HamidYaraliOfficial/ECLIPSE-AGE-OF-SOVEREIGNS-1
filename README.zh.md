# ECLIPSE: AGE OF SOVEREIGNS（日蚀：君主时代）
[English](README.md) | [فارسی](README.fa.md) | **中文**

一款运行在浏览器中的 3D 大战略游戏（Three.js，无需构建）。作者：**Hamid Yarali** — https://github.com/HamidYaraliOfficial

## 状态：垂直切片 v0.1
已实现并通过测试：3D 地球（旋转、缩放、选择城市）、1 个玩家国家 + 3 个 AI 国家、5 座城市、经济系统（金钱、食物、铁、能源、人口、幸福度、税收）、8 项分支科技树、招募、自动结算战斗（科技、士气、补给、地形）、外交（贸易协定、宣战、和平，AI 会记住玩家行为）、会行动的 AI、胜利条件、存档/读档（3 个存档位 + 自动存档，带版本号和校验和，损坏存档会被安全拒绝）。

**尚未实现（因此不会在游戏中显示）：** 实时 3D 战术战斗、天气、间谍、内政派系、200+ 科技、40+ 国家、音频、多人联机、调试面板。

画面：HDR 泛光、电影级色调映射、带凹凸的程序化地形、夜面城市灯光、动态云层、大气着色器、昼夜循环、领土光环、动态贸易（金色）与战争（红色）航线、电影式开场。另有：基于游戏状态的动态事件引擎与自适应音频。

## 运行
```
npm start    # 或: python3 -m http.server 8080
```
打开 http://localhost:8080（首次需联网加载 Three.js）。空格键 = 结束回合。

## 测试
```
npm test
```
